# LangGraph is the outer graph; the Planner is the root agent inside it

The spec has two orchestrators: a LangGraph state machine and a DeepAgents Planner that spawns researchers via `task`. We made LangGraph the outer graph. The Planner is the `create_deep_agent()` root agent the assignment requires, and it spans two graph nodes on one checkpointed thread: `PLANNING`, where it produces the Sub-task plan, and `RESEARCHING`, where the graph resumes it to dispatch Researchers via `task`. The graph advances only once all branches return. Typed graph state is the contract between stages, so "parallel branches finish before synthesis" is enforced by the graph and not left to the Planner's judgement. An earlier version ran a separate supervisor agent in `RESEARCHING`. We dropped it because the assignment and its rubric require the Planner itself to spawn the Researchers.
